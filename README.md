# 🚀 CatchUp - 경기대 맞춤형 공지사항 요약 및 일정 관리 서비스

> **VLM(Vision-Language Model)을 활용하여 공지사항과 개인 일정을 스마트하게 관리하는 대학생 필수 앱**



## 📌 프로젝트 개요

* **서비스 명:** CatchUp
* **주요 타겟:** 공지사항을 일일이 확인하기 번거로운 경기대학교 학생
**핵심 기능:** * 학교 홈페이지 공지사항 자동 수집 및 **3줄 요약** 


* 공지사항 내 **마감일 자동 추출** 및 D-Day 알림 


* 손글씨, 포스터 등 이미지 인식을 통한 **개인 일정 자동 등록** 





## 🛠 Tech Stack

* **Frontend:** React Native (Expo)
  
* **Backend/DB:** Supabase (PostgreSQL) 

* **AI Model:** VLM (GPT-4o 기반 멀티모달 모델) 

* **Crawler:** Python (BeautifulSoup)
